# Kisan Dost

## Overview

Kisan Dost is an AI-powered agricultural voice assistant designed
to help farmers access agricultural information in simple Urdu.

## Problem

Many farmers face difficulty accessing agricultural experts and
digital information because of language and digital-literacy barriers.

## Solution

Kisan Dost allows farmers to ask agricultural questions in Urdu
through voice and receive simple, practical guidance in Urdu.

## Core User Flow

Farmer speaks
→ Speech-to-Text
→ Question understanding
→ Farmer + crop + weather context
→ Agricultural knowledge
→ AI response
→ Urdu Text-to-Speech
→ Farmer hears response

## Target User

Farmers who prefer Urdu and may have limited digital literacy.

## Core Features

- Farmer profile
- Crop selection
- Location
- Weather information
- Urdu voice input
- Agricultural AI assistant
- Urdu voice output
- Conversation history

## MVP Scope

The MVP should demonstrate the complete voice-to-voice
agricultural assistance workflow.

## Non-Goals

The MVP is not intended to:

- Replace agricultural experts
- Provide guaranteed diagnoses
- Provide unrestricted medical/veterinary advice
- Build a fully autonomous farming system
- Train a proprietary LLM
- Build an unnecessarily complex AI infrastructure
